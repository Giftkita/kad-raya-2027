Cara guna

  1. Isi borang di bawah dan tekan "Tambah ke katalog". Ulang untuk setiap barang.
  2. Tekan "Terbitkan" di bawah skrin. Katalog terus masuk ke laman kau dalam 1 hingga 2 minit.
  3. Kali pertama sahaja: sambung token GitHub di bahagian "Terbit terus ke laman".

Terbit terus ke laman

Sambung sekali sahaja. Lepas tu butang "Terbitkan" hantar katalog terus ke laman kau, tanpa perlu upload ke GitHub.

Cara dapatkan token (sekali sahaja)
  1. Buka github.com/settings/personal-access-tokens/new dan login.
  2. Token name: tulis apa-apa, cth "katalog". Expiration: pilih tempoh paling lama.
  3. Repository access: pilih "Only select repositories", kemudian pilih .
  4. Permissions, Repository permissions, Contents: tukar kepada "Read and write".
  5. Tekan "Generate token", salin token tu, dan tampal di kotak di atas.

Token disimpan dalam browser telefon ni sahaja, bukan dalam laman. Jangan kongsi token dengan sesiapa.
